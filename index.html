Why you can trust this page

A QR code with your password is only safe if the page that makes it keeps the password to itself. You can check that yourself, no technical knowledge needed.

  1. It works offline. Once the page is open, switch off Wi-Fi or turn on airplane mode, then fill in the form. The QR code still appears. A page with no connection can't send anything.
  2. Your browser forbids it to send data. The page carries a security rule (a Content-Security-Policy) that your browser enforces, not us: it blocks every connection, form submission and outside image. Even if someone changed the code to send your password, the browser would refuse.
  3. Nothing is saved. No account, no cookies, no analytics, no storage. Reload the page and the form is empty again.
  4. All the code is public. The page is three short files on GitHub, served exactly as they are there. Anyone can read them, and every change is visible in the history.
  5. Or leave the password out. Leave the password field empty. The code then sets up the server and the user name, and you type the password on each device in Pixette.

For developers: open the developer tools, Network tab, and type in the form. No request appears. The policy is the first tag in the page source.

Make the code with another QR generator

Any QR generator works. Use this text, with every value URL-encoded (for example @ becomes %40):

pixette://connect?protocol=<type>&url=<server URL>&user=<user>&password=<password>
ParameterUsed byValue
protocolallwebdav (default), smb, synology_photos, immich or jellyfin
urlall but SMBFull server URL with http:// or https://
hostSMBHost name or IP address
portSMBOptional, default 445
shareSMBShare name
userallUser name (Immich: your email)
passwordallAlways include it, even empty: password=

Examples:

pixette://connect?url=https%3A%2F%2Fnas.local%3A5006%2Fphotos&user=john&password=secret
pixette://connect?protocol=smb&host=192.168.1.100&share=Photos&user=john&password=secret
pixette://connect?protocol=jellyfin&url=http%3A%2F%2F192.168.1.100%3A8096&user=john&password=

Plex and OneDrive can't be set up with a QR code: Pixette signs in to them on the device itself.
